# 네이버 블로그 글쓰기 앱

이 앱은 네이버 블로그 최적화 구조를 기반으로 한 글쓰기 도우미입니다. 상위 3개 블로그 벤치마킹 기준을 반영해 제목, 요약, 소제목, 이미지, 키워드, CTA를 빠르게 생성할 수 있습니다.

## 구성
- `index.html`: 앱 화면과 입력 폼
- `style.css`: 간단한 스타일
- `app.js`: 글 구조 생성 및 미리보기 로직

## 사용 방법
1. `blog_writer_app` 폴더를 브라우저에서 엽니다.
2. 제목, 요약, 인트로, 섹션, 이미지 URL을 입력합니다.
3. `글 구조 생성` 버튼을 눌러 미리보기와 Markdown을 확인합니다.
4. 생성된 Markdown을 복사하여 네이버 블로그 에디터에 붙여넣습니다.

## 배포 방법
- 정적 사이트로 배포 가능: GitHub Pages, Netlify, Vercel 등
- 배포 후 블로그 링크를 공유하거나, 포스트 작성 시 해당 도구를 활용하세요.

## 배포 Tip
- 정적 호스팅 URL을 블로그 소개 글에 추가하면, 다른 사람도 동일한 구조를 활용할 수 있습니다.
- Naver 블로그에 직접 올릴 수는 없으므로, 작성된 Markdown/HTML을 복사하여 사용하세요.
